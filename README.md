# Fleet Management System

A responsive and user-friendly Fleet Management System designed to simplify vehicle management and help fleet managers maintain important vehicle-related records through a centralized dashboard.

The project includes a Landing Page that introduces the platform, highlights its key features, explains its modules, and helps users understand how the system works. It also includes an Admin Dashboard for managing fleet-related information and monitoring vehicle operations.

## 📌 About the Project

The Fleet Management System is designed to help businesses and fleet managers organize and manage their vehicle operations efficiently.

Using this platform, fleet managers can maintain vehicle records, track fuel consumption, monitor maintenance activities, check battery health, and manage other essential vehicle information from one place.

The system aims to make fleet operations more organized, accessible, and easier to manage.

## 🛠️ Technologies Used

- HTML5 – Structure and content of web pages.
- CSS3 – Styling and layout customization.
- Bootstrap 5 – Responsive design and UI components.
- JavaScript – Interactive functionality and dynamic user interactions.

## 🎯 Target Users

This platform is designed for:

- Fleet Managers – To manage and monitor fleet operations.
- Transport Companies – To organize vehicle-related information.
- Logistics Businesses – To maintain vehicle records and operational details.
- Vehicle Owners – To keep track of vehicle maintenance and fuel records.
- Fleet Administrators – To manage vehicle information and monitor fleet activities.

## 🔗 Website Navigation

The project contains two connected sections:

- **Landing Page:** Introduces the platform and its features.
- **Admin Dashboard:** Provides access to fleet management modules.

Users can navigate from the landing page to the admin dashboard and return to the landing page using the dashboard logo.
